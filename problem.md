# Pseudocode for Lab 03 Problems

## Problem 1: Display Student Information
1. START
2. Declare variables for Name, Roll No, Age, Height, GPA, and Section.
3. Read input for each variable using appropriate data types.
4. Display the stored values in a formatted layout using printf().
5. END

## Problem 2: Read and Display Characters using getchar() and putchar()
1. START
2. Declare char variables to store three characters.
3. Read the first character using getchar().
4. Read the second character using getchar().
5. Read the third character using getchar().
6. Output each character using putchar().
7. END

## Problem 3: Display Floating-Point Value with Precision
1. START
2. Declare float and double variables.
3. Read values from the user.
4. Print value with default precision.
5. Print value formatted to 2 decimal places (%.2f).
6. Print value formatted to 4 decimal places (%.4f).
7. Print value formatted to 6 decimal places (%.6f).
8. END
